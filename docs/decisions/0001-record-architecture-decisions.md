# 0001 · 记录架构决策

日期：2026-11-26

## 状态

已采纳

## 背景

本项目（mygo-antdesign）是长期的控件库工程，涉及主题映射、密度、控件换肤、示例体系等多个需要取舍的决策点。决策及其上下文若只散落在代码评审或聊天记录里，后续贡献者（包括 AI 助手）将无法追溯「为什么这样做」。

## 决策

采用轻量 ADR（Architecture Decision Record）流程：

- 每个重要取舍写一份 `NNNN-<标题>.md`，放入 `docs/decisions/`。
- 格式：背景 / 决策 / 后果 三段，尽量短。
- 决策变更时新建编号文件并标注旧决策状态为「已取代」，不修改历史文件。

## 后果

- 正向：决策可追溯；AI 助手与新人按 ADR 即可理解约束，无需考古。
- 负向：多一份文档维护成本，接受。
